NOIRE — LUXURY FASHION STOREFRONT
=================================

FILES
-----
index.html       Main website document
style.css        Premium styling, responsive layouts and motion
script.js        Navigation, product filters, search, favorites and shopping bag
NOIRE-Preview.html  Self-contained preview file (CSS and JavaScript embedded)

RUN IT
------
1. Extract this folder somewhere on your computer.
2. Keep index.html, style.css and script.js together in the same folder.
3. Double-click index.html to open it in Chrome, or open the folder in VS Code and use Live Server.
4. Keep an internet connection enabled for remote product photography and Google Fonts.

No package installation or build tools are required.

WHAT WORKS
----------
- Responsive home, shop, story, journal and contact views, navigated from the top menu.
- Category filters, sorting, product search and quick-view modal.
- Size selection, add-to-bag, quantity controls, remove item and subtotal.
- Favorites and cart saved to browser localStorage.
- Newsletter/contact demo feedback, scrolling reveals, hover details and mobile menu.

DEMO LIMITS
-----------
This is a front-end storefront prototype. It does not take payments, transmit contact forms,
manage real stock, or create user accounts. A secure backend/payment provider is required
for a production store. Prices are sample PKR prices. Product photographs load from Unsplash;
if a particular remote photo is unavailable, replace its URL in script.js or index.html.
